# Yuvaraj S - Portfolio Website 🚀

A stunning, animated portfolio website built with **Flutter Web** showcasing my projects, skills, and experience as a Flutter Developer.

![Flutter](https://img.shields.io/badge/Flutter-02569B?style=for-the-badge&logo=flutter&logoColor=white)
![Dart](https://img.shields.io/badge/Dart-0175C2?style=for-the-badge&logo=dart&logoColor=white)

## ✨ Features

- 🎨 **Modern Dark Theme** with gradient accents
- 🌟 **Animated Background** with floating particles
- 📱 **Fully Responsive** - Desktop, Tablet & Mobile
- ⚡ **Smooth Animations** using flutter_animate
- 🖱️ **Interactive Cards** with hover effects
- 📝 **Typewriter Effect** for role titles
- 🔗 **Social Links** integration
- 🎯 **Project Showcase** with expandable details

## 🛠️ Tech Stack

- **Framework:** Flutter 3.47.2
- **Language:** Dart 3.13.2
- **Animations:** flutter_animate, animated_text_kit
- **Fonts:** Google Fonts (Poppins, Inter, Fira Code)
- **State:** Stateful Widgets
- **Deployment:** GitHub Pages

## 🚀 Getting Started

### Prerequisites
- Flutter SDK 3.13+
- Dart SDK 3.13+

### Installation

```bash
# Clone the repository
git clone https://github.com/yuvaraj133433-tech/yuvaraj-portfolio.git

# Navigate to project directory
cd yuvaraj-portfolio

# Get dependencies
flutter pub get

# Run locally
flutter run -d chrome
```

### Build for Production

```bash
flutter build web --release
```
